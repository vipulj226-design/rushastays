## CONSOLIDATED ISSUE SUMMARY

### 1. 🔴 CRITICAL ISSUES (Must Fix)
1. **Property page canonical URLs are WRONG** — point to `/filename.html` instead of `/properties/filename.html`. This can cause Google to deindex all property pages.
2. **Loading unminified CSS + JS in production** — `styles.css` (113 KB) and `app.js` (56 KB) instead of minified versions. ~38 KB wasted per pageview.
3. **`@import` Google Fonts in CSS** — creates a render-blocking waterfall chain.

### 2. 🔴 HIGH PRIORITY ISSUES
4. **404.html missing `<meta name="robots" content="noindex">`** — search engines may index the 404 page.
5. **Zero `loading="lazy"` on images** — all images load immediately on every page.
