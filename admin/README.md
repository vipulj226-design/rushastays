# 🏢 Rusha Stays Admin Panel & CMS Documentation

Welcome to the **Rusha Stays Content Management System**.

## 📌 Features Overview

- **📊 Dashboard**: Real-time KPI metrics, active inventory counter, and recent callback enquiries.
- **🏢 Property Management**: Create, edit, publish/draft properties, manage image galleries, pricing, locality tags, and landmarks.
- **✍️ Blog Articles**: Create and edit blog articles with auto-slug generation, cover images, and category tagging.
- **❓ FAQs**: Manage accordion questions and answers that feed into the public FAQPage schema.
- **💬 Testimonials**: Control client reviews displayed in the homepage carousel.
- **📥 Enquiries Inbox**: Track incoming guest callback requests, update statuses (New &rarr; Read &rarr; Contacted &rarr; Closed), and initiate direct 1-click WhatsApp chats or calls.
- **🖼️ Media Library**: Upload images to cloud storage and copy CDN links.
- **⚙️ Site Settings**: Update contact information, WhatsApp float number, and Supabase credentials.
